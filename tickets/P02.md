## Ràng buộc từ code client (đã kiểm chứng, xem `evidence/P02-noise-client-research.md`)

Đọc tại `tailscale.com@v1.105.0-pre.0.20261112091541-a2da5fbcaa53`:

- **Client thử HTTP thường ở cổng 80 trước**, rồi sau 500 ms mới đua thêm cổng 443 (`control/controlhttp/client.go:93, 253-258`). Trên cổng 80 không có SNI, chỉ có `Host: <host>:80`.
- **Client không kiểm tra cert TLS khi upgrade `/ts2021`.** Lỗi verify chỉ được ghi log (`control/controlhttp/client.go:493-502`). `/key` thì được lấy qua HTTPS có verify (`control/controlclient/direct.go:1543`).
- Machine key dùng chung cho mọi profile trên thiết bị. Node key riêng theo từng profile.

**Hệ quả với thiết kế:**

1. Không gắn tailnet chỉ bằng SNI. Server chọn tailnet theo `Host` đã chuẩn hóa (bỏ port, lowercase). Khi chạy TLS thì SNI phải khớp với Host. Host lạ bị từ chối.
2. Ràng buộc thật là Noise IK. Client chỉ biết public key của tailnet nó lấy từ `/key`. Server **không được** thử lần lượt key của nhiều tailnet.
3. Edge và listener phải phục vụ `/ts2021` trên cả cổng 80 lẫn 443 và giữ nguyên `Host`.
4. Client không tự hồi phục khi key bị đổi trong lúc đang kết nối. Phần `RotateIdentityKey` và việc chuyển tenant (P12b) phải giữ nguyên key.

RED test bổ sung: upgrade `/ts2021` trên cổng 80 với `Host` A và B → mỗi Host chỉ bắt tay được bằng key của chính tailnet đó. Header `Host` có port `:80` và `:443` phải được chuẩn hóa giống nhau.

**Gợi ý POC:** để tránh state chưa scoped làm lẫn dữ liệu, POC được phép dựng hai runtime tách biệt trong cùng process (theo hướng ADR 0001). Mọi đường tắt chỉ dành cho POC phải ghi rõ trong evidence và không được merge như thiết kế cuối.

## Điều kiện dừng

- **Nếu client thật không tương thích với Noise key theo tailnet trong process chung: DỪNG PR, viết ADR** (`design/adr/`), kèm log protocol đã redact, mô tả phương án thay thế theo `03-isolation-threat-model.md` §3 (ưu tiên: tách front listener/virtual server identity theo tailnet trong cùng process), rồi chờ duyệt. **Không** tự chuyển sang một Noise key chung cho shard và không tuyên bố isolation (AGENTS rule 12).
- Client cache key theo cách làm profile A dùng key B: dừng, ADR.
- Cần sửa code Tailscale client: dừng, ADR.
