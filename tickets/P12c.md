## Phạm vi

### Nhóm A — cô lập dữ liệu và policy (ưu tiên 1)

| ID | Việc | Test RED bắt buộc (fail trước khi sửa) |
|---|---|---|
| A1 | `tenantscope`: điều kiện tenant phải AND với **toàn bộ** WHERE có sẵn (bọc nhóm), cả SELECT/UPDATE/DELETE/Row | Dưới scope A: `Where(x).Or(y).Find` không trả dòng của B; `Where(id=a).Or(id=b).Delete` không xóa dòng của B (SQLite + PostgreSQL) |
| A2 | `tenantscope`: câu lệnh nêu bảng tenant (`users`, `nodes`, `credentials`, `policies`, `tailnet_settings`) qua `Table()`, `TableExpr`, `Joins` dạng chuỗi hoặc đích không có schema tenant → lỗi (`ErrNoScope` hoặc lỗi mới), không bao giờ chạy không scope | `Table("nodes").Find(&dto)`, `Table("credentials").Create(map)`, `Table("nodes").Where(…).Updates(map)`, `Model(&Tailnet{}).Joins("JOIN nodes …").Scan` → lỗi; đường hợp lệ hiện có (`migrations`, `Joins("AuthKey")`) vẫn chạy |
| A3 | `tenantscope`: UPDATE/Save/Updates gán `tailnet_id` khác scope → lỗi | `Update("tailnet_id", B)`, `Updates(map{"tailnet_id": B})`, `Save(&row với TailnetID=B)` dưới scope A → lỗi, dòng không đổi |
| A8 | Migration mới (nối cuối, trong transaction, SQLite + PostgreSQL, cập nhật `schema.sql`/`schema_postgres.sql`): trigger `BEFORE UPDATE OF tailnet_id` trên mọi bảng tenant từ chối đổi `tailnet_id` | SQL thô `UPDATE nodes SET tailnet_id = …` → lỗi trên cả hai DB; migration nâng DB cũ giữ dữ liệu |
| A4 | Guard SQL thô: xét **mọi** `Raw`/`Exec`/`ExecContext`/`Query`/`QueryContext`/`QueryRow*`; SQL phân giải được (hằng, const, ghép hằng) thì so khớp **đọc và ghi** bảng tenant ở mọi cú pháp (kể cả `INSERT OR REPLACE`, `REPLACE INTO`, `UPDATE ONLY`, tên có schema, `MERGE`, `TRUNCATE`); SQL không phân giải được trong package chạm DB → báo; allowlist theo **từng câu** (file + băm SQL chuẩn hóa) kèm lý do | Thêm tạm một `Raw("SELECT * FROM nodes …")`, một câu SQL qua biến, một `INSERT OR REPLACE INTO nodes` → guard fail; allowlist hiện có được chuyển sang dạng mới, không nới |
| A5 | `schema_test.go`: mọi bảng có cột `tailnet_id` thì `NOT NULL` + FK tới `tailnets`; SQLite ≡ PostgreSQL (bảng, cột, unique, FK); CI chạy test PostgreSQL (service container hoặc tương đương, không secret thật) | Xóa tạm `NOT NULL` của một bảng → test fail |
| A6 | Policy rỗng khi reload (cluster mode, `PolicyEmptyDenies`) → cài deny ngay (`SetPolicy(nil)` → `{}`); CLI `tailnet policy` validate trước khi lưu (rỗng thì phải là ý định rõ ràng) | Servertest: tailnet có policy cho phép, operator lưu rỗng → sau reconcile client không còn thấy peer, filter rỗng; CLI từ chối policy không parse được |
| A7 | `ScopedContext`: trả lỗi khi context đã gắn tailnet khác (hoặc xóa hàm nếu không dùng) | Gọi với context đã gắn B → lỗi |
