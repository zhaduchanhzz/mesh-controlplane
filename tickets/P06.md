# P06 — Policy/ACL, DNS, routes, exit node giữa các tailnet

- **Trạng thái:** `Verified`, đã merge vào `master` (2026-11-24, theo lệnh chủ dự án); chưa `Reviewed`. Bằng chứng: `evidence/source-inventory-P06.md` §5–§9.
- **ADR:** [0008](../design/adr/0008-per-tailnet-dns.md) (DNS theo tailnet, Accepted 2026-11-24).
- **Phụ thuộc:** P05 (runtime theo tailnet), P03b (`tenantscope`), P10 (revision + reconcile, fence `LockOwnership`).

## Mục tiêu

Không có đường nào để policy, DNS, route, exit node hay tag của một tailnet ảnh hưởng tới tailnet khác trong cùng process cluster (I02, I05, I07; S06–S09; AGENTS 8).

## Phạm vi (đã chốt với chủ dự án 2026-11-24)

1. **IP overlay unique theo tailnet**: migration `202611241200-nodes-ip-unique-per-tailnet`, unique `(tailnet_id, ipv4)` / `(tailnet_id, ipv6)` bỏ qua NULL; hai tailnet được trùng IP.
2. **DNS theo tailnet (ADR 0008)**: base domain `<slug>.<base>` do hệ thống đặt; DNS tenant (MagicDNS, nameservers, split, search, extra_records) trong bảng `tailnet_settings`, revision `tailnets.config_revision`, nạp lại qua reconcile; `Config` riêng cho mỗi runtime; giới hạn `tuning.tenant_dns.*`; CLI `cluster tailnet dns`; cluster từ chối DNS dạng tenant trong config.
3. **Test isolation**: S06 (IP/hostname/subnet route trùng), S08 (auto-approver và exit node), S09 (tagOwners), wildcard `*` (I05), policy derpMap.

## Ngoài phạm vi

- API v2 cho tenant ghi DNS (ADR 0008 Q-b).
- Bầu chọn primary khi nhiều router HA cùng subnet; gắn tag qua đăng nhập web (cluster mode chưa có).
- Đổi slug (ADR mới nếu cần).
